# 0.1.0 — Initial Release

Battle Arena Toshinden Recompiled is believed to be stable based on gameplay
testing and user validation, despite being an early release.

- Native Windows x64 package and Linux x86_64 AppImage.
- Faithful default presentation with recomp-ui settings and disc selection.
- Optional adaptive widescreen, including 21:9, with proportional HUD text.
- Optional Gaia and Sho EXTRA selection rows with revised portraits.
- Optional frame blending and desperation moves at any health.
- Two-player rollback netplay, with standard controller ports and no Multitap.

The Gaia/Sho selector's navigation hint has been removed for a cleaner menu.

Netplay clears mods for a vanilla session. Two local peers passed independent
input and combat checks, with 416 matching sampled state hashes and no reported
desyncs. The online lobby browser connects; internet matches and NAT traversal
have not yet been validated for this title.

Provide your own USA 14-track BIN/CUE disc image. No disc data or retail BIOS
is included; MIT-licensed OpenBIOS is bundled. See README.md for setup details.
