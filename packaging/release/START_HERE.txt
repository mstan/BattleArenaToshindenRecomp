Battle Arena Toshinden Recompiled @VERSION@

Extract the Windows ZIP into a writable folder and keep its files together.
Choose your own USA SCUS-94200 CUE/BIN disc set in the launcher. Keep all
fourteen tracks beside the CUE so original CD audio remains available.
The compiled public runtime and MIT-licensed OpenBIOS are bundled; original
game media and retail BIOS are not included.

Fresh profiles use the shared Internal Resolution mod at 4x. Its 1x through
32x choices are bounded by GPU texture and memory limits. Saved mod choices
remain authoritative; disabling Internal Resolution selects native resolution.
CD Speed and Fast Loading packages are excluded.

The title's adaptive/fixed widescreen, frame blending, Gaia/Sho Extra Roster,
independent alternate portraits and desperation-command enhancements remain
optional and disabled by default. The digital controller lock is retained.
Configure your connected controller in the launcher. Select changes costume
and portrait on character selection. Native memory-card saves and settings
remain local; no personal state is bundled.

NETPLAY uses the existing two-player negotiated session path. Online hosts
can select Extra Roster through Mods; both players require matching builds,
packages and the verified fourteen-track disc. Existing gameplay/netplay
observations are documented in README.md and validation/README.md; this
release does not claim a new netplay, performance or gameplay campaign.

The current release is a Windows build. Source retains the shared Linux
AppImage command; an older Linux artifact remains in the v0.1.3 release.
See README.md and RELEASE_NOTES.md for build instructions and limitations.
